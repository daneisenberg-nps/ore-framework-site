# Operational Resilience Engineering

This repository contains the source for the independent research website for
**Operational Resilience Engineering (ORE)**.

ORE connects operations research and resilience engineering to develop formal
models of vulnerability, resilience, .ystem performance, and intervention
choices in critical operational systems. The motivation of this project is to advance the [Theory of Graceful Extensibility](https://link.springer.com/article/10.1007/s10669-018-9708-3) developed by David Woods (Ohio State) via novel decision theory and methods for systems modeling via optimization and simulation.

## Status

The website and research framework are under active development.
